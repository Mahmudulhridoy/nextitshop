## Security Checklist After Delivery

1. Back up the TData folder or session file in a private, encrypted location.
2. Change the two-step verification password and store it in a password manager.
3. Review **Settings → Devices** and end sessions you do not recognise.
4. Do not open the same session from many places at once.
5. Follow Telegram's rules: no unsolicited bulk messaging and no spam.

## Frequently Asked Questions

### What is Telegram TData?

TData is the folder Telegram Desktop uses to store a logged-in account. Copying it to another Telegram Desktop installation opens the same account.

### What is a Telegram session file?

It is a file used by libraries like Telethon and Pyrogram to keep an account signed in through the API.

### Which format should a beginner choose?

TData. It needs nothing except the Telegram Desktop app.
