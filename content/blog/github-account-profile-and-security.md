Recruiters, clients and open-source maintainers all do the same thing before they reply to you: they open your GitHub profile. A tidy profile with a secure account says more about your habits than a long list of skills.

## Make the profile work for you

**Add a profile README.** Create a repository with the same name as your username and add a `README.md`. Introduce yourself in three sentences, list what you are working on, and say how people can reach you.

**Pin your best repositories.** You can pin up to six. Choose projects with a clear description, a README and some screenshots.

**Use a real photo or consistent logo.** It makes your profile feel like a person or business, not an anonymous account.

## Lock down the account

1. **Enable two-factor authentication.** Use an authenticator app or a security key.
2. **Download your recovery codes.** Keep them offline.
3. **Add an SSH key** instead of typing a password for every push.
4. **Review authorized apps** under Settings and remove any you no longer use.

## Build habits that show you care

- **Commit small and often**, with messages that explain the change in plain language.
- **Write a README for every project:** what it does, how to run it, and how to contribute.
- **Use issues and pull requests** even on solo projects. They show how you work.
- **Sign your commits** to earn the "Verified" badge.

## Protect your main branch

On any repository that matters, go to **Settings → Branches** and add a rule that:

- Requires a pull request before merging
- Requires status checks to pass
- Blocks force pushes

This takes two minutes and prevents most accidental disasters.

## A healthy long-term routine

Check your GitHub notifications once a day, review open pull requests weekly, and archive repositories you no longer maintain. A profile that looks active and organised is a real advantage.

## Frequently Asked Questions

### What is a GitHub profile README?

It is a README.md in a repository named after your username. It appears at the top of your profile.

### How many repositories can I pin?

You can pin up to six repositories on your GitHub profile.

### Why enable branch protection?

It stops accidental force pushes and requires reviews or checks before code reaches your main branch.
